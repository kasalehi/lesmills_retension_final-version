================================================================================
                          HOW CSV IS CREATED
================================================================================

FLOW:
1. read_data_task()
   → Gets weekly engagement data

2. snapshots_task()
   → Calculates ews_pct and risk_band from engagement

3. ingest_task()
   → Retrieves 25 SQL features
   → INNER JOIN with snapshots (adds ews_pct, risk_band)
   → Removes 'Churned' column (we're predicting, not training)
   → Outputs: df_merged_*.parquet (27 feature columns)

4. model_task()
   → Loads trained model (model_balanced_*.pkl)
   → Makes predictions on 27 features
   → Outputs: ChurnedPrediction (0, 1, or 2)

5. save_task() → save_predictions()
   → Loads features from df_merged_*.parquet (27 columns)
   → Adds ChurnedPrediction column from model output
   → Adds RunDate from Airflow Variable
   → Renames end_date → EndDate
   → Reorders columns: MembershipID | ChurnedPrediction | EndDate | RunDate | [features]
   → Saves to CSV: predictions_YYYYMMDD_HHMMSS.csv

================================================================================
                          USAGE EXAMPLES
================================================================================

EXAMPLE 1: Find all high-risk members (Churn 0-3 months)
  SELECT MembershipID, EndDate, ews_pct, risk_band
  FROM predictions_YYYYMMDD_HHMMSS.csv
  WHERE ChurnedPrediction = 0
  ORDER BY ews_pct DESC;

EXAMPLE 2: Validate predictions (compare predicted vs actual churn)
  SELECT
    MembershipID,
    ChurnedPrediction,
    EndDate,
    CASE WHEN EndDate > RunDate AND EndDate <= DATEADD(MONTH, 3, RunDate) THEN 'Actual_Churn_0-3mo'
         WHEN EndDate > DATEADD(MONTH, 3, RunDate) AND EndDate <= DATEADD(MONTH, 6, RunDate) THEN 'Actual_Churn_3-6mo'
         ELSE 'No_Churn_Or_Later'
    END AS ActualChurn
  FROM predictions_YYYYMMDD_HHMMSS.csv;

EXAMPLE 3: Find members with high EWS but low risk band
  SELECT MembershipID, ews_pct, risk_band, ChurnedPrediction
  FROM predictions_YYYYMMDD_HHMMSS.csv
  WHERE ews_pct > 0.8 AND risk_band = 'Low'
  LIMIT 10;

EXAMPLE 4: Export for retention campaign
  SELECT MembershipID, Gender, Age, ClubName, ews_pct
  FROM predictions_YYYYMMDD_HHMMSS.csv
  WHERE ChurnedPrediction IN (0, 1)
  ORDER BY ews_pct DESC;


================================================================================
                         IMPORTANT NOTES
================================================================================

1. NO Churned column in output
   - Only in training data (ingestfortrain.py)
   - Predictions use ChurnedPrediction instead

2. Features are NOT scaled/transformed
   - Raw values in CSV (as they came from SQL)
   - Model was trained with preprocessor, but output CSV has original values

3. EndDate can be NULL
   - NULL means member is still active (no end date)
   - Compare with RunDate for churn calculation

4. All rows in CSV are eligible members
   - >= 12 visits in past 12 months (from read_data eligibility)
   - Have snapshot data (ews_pct, risk_band)

5. Row count should match ingest_task output
   - Filtered by: Active members + Eligible engagement + Has snapshots
   - Typically 80-90% of total active member base
